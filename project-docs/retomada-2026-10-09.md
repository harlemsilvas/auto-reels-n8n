Verificacoes HTTP locais realizadas:

| Requisicao | Resultado |
| --- | --- |
| GET conversas sem cookie | 401 |
| GET conversas com sessao administrativa | 200, duas conversas |
| POST send com cookie, sem CSRF, corpo vazio | 403 |
| POST send com cookie e CSRF, corpo vazio | 400 de validacao |
